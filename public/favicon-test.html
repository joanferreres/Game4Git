Favicon Test Page

This page is designed to test if the favicon appears properly in the browser tab.

Available Favicon Files

favicon.ico

Classic .ico format used by all browsers

favicon-16x16.png

16x16 PNG for older browsers

favicon-32x32.png

32x32 PNG for most browsers

apple-touch-icon.png

180x180 PNG for iOS

logo.png

Full-size logo

How to Fix Favicon Issues

  1. Clear browser cache (Ctrl+Shift+Delete or Cmd+Shift+Delete)
  2. Hard refresh (Ctrl+F5 or Cmd+Shift+R)
  3. Try a different browser
  4. Try incognito/private mode
